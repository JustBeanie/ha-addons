# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub instead:
[**Report a vulnerability**](https://github.com/JustBeanie/ha-addons/security/advisories/new)

Include the app name and version, what you found, and how to reproduce it. You'll get a reply as soon as possible, and a fix will be released before the details are made public.

## Supported versions

Only the latest version of each app is supported. Update from **Settings → Apps** before reporting.

For BACnet MQTT Gateway and ToneWatch, application code lives in
[JustBeanie/bacnet-mqtt-gateway](https://github.com/JustBeanie/bacnet-mqtt-gateway) and
[JustBeanie/tonewatch](https://github.com/JustBeanie/tonewatch); reporting here is fine either way.

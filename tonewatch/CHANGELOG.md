# Changelog

## 0.6.1

- Track app release 0.6.1: malformed requests now return a validation error
  instead of a server error, and token/live-URL expiry times are ISO 8601.

## 0.6.0

- Admin tooling: system health, admin alerts, delivery log with retry,
  end-to-end drill, config history with rollback/export/import, backup and
  restore, support bundle and log viewer, credential management, maintenance
  (retention, checkpoint/vacuum, orphan cleanup), opt-in Prometheus metrics,
  audit log and draft replay.

## 0.5.0

- CAD incident correlation, agencies and map, Meshtastic notification target.

## 0.4.0

- Live audio restream with signed URLs, software and automatic squelch.

## 0.3.0

- Add the first published multi-architecture image target.
- Add Home Assistant ingress, media, audio, USB, MQTT service, discovery, and
  hot-backup manifest settings.
- Document M10a options, Supervisor MQTT credentials, recordings, and device
  mapping.
